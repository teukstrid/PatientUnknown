12.11.2026
Today we had playtests. I felt a bit apprehensive about it beforehand, but it turned out very fun. Having a background in QA, I felt in my element and it was fun getting to talk to co-students I havent talked with before and get their input on the game. The input was very much the same, so it was clear that some of my own concerns was valid and some things I didn't think would be necessary, like a tutorial, was wanted. I have decided to implement some of the
"solutions" to the problems the playtesters were experiencing. But due to the genre, I will not fix all things.

Things I will fix:
* Brief tutorial bloodspatter on the wall
* Move location of objective marker
* Tooltip over syringe
* Add more chase juice (this was already on my todo list)

What I don't feel like I have time to add, but could in the future:
* Add a crouch
* Narrative

What I don't think I will add:
* Add so that all doors can be opened. You shouldnt be allowed to access all rooms.
* Add functionality to light switches. While it would be cool, it is not imperative for the gameplay.
* Add a tutorial level. It is a game where you learn by doing (if it was a full game, maybe but not for a prototype)
